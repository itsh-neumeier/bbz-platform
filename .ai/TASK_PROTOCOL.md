# .ai/TASK_PROTOCOL.md

For every task:
1. Link GitHub Issue.
2. Write implementation plan.
3. Identify affected modules.
4. Check ADR impact.
5. Create branch.
6. Implement smallest coherent change.
7. Add/update tests.
8. Run lint/type/test.
9. Update docs/current state.
10. Open PR.

PR description must include:
- Problem
- Solution
- Files/modules
- Tests
- Security impact
- HA impact
- Rollback
