# Cayuga → Coda Video (moved)

"Cayuga" was the early planning name for the video platform. The canonical
integration is now **`coda_video` (HxGN dC3 Video)**.

**See [`INTEGRATIONS_CODA_VIDEO.md`](./INTEGRATIONS_CODA_VIDEO.md)** for the full
baseline. Decision recorded in **ADR-0006** and **ADR-0016**.

"Cayuga" survives only as a migration/display alias where an existing environment
requires it. New code, configuration and documentation use `coda_video`.
